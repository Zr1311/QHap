# Retained component-optimizer evidence

This archive preserves supplied edge lists and checkpoint/energy summaries associated with the original solver-comparison work. The read component has 8,742 nodes and 259,417 edges, all non-negative; the SNP component has 7,768 nodes and 3,303,740 edges, including signed weights. These sizes match the original Figures 2–3 captions. `MANIFEST.json` records original and compressed checksums. Decompress each `.gz` before use. Original manuscript figures are not regenerated or replaced by these records.

Checkpoint tables contain iteration, maximum/minimum/mean cut, cut standard deviation and timing columns. Energy summaries separately record CPU/GPU configurations. The supplied `maxcut_v4` sources are preserved unchanged under `../solver_comparison_snapshot/`. A new invocation can use an explicitly decompressed graph with `--file`, `--solver`, `--n_iter`, `--batch_size` and `--device`; defaults in those archived files are not a complete recovered invocation for every plotted curve. They import MindQuantum validation utilities, and SA additionally uses `neal`. An execution attempt in the phasing test environment stopped at the missing optional MindQuantum dependency; these historical comparison programs are not included in the claim that the corrected phasing paths passed functional tests.

The retained summaries do not recover every individual repeat seed or establish the exact source version and plotting file for the final composite images. In particular, a separate retained plotting helper shades minimum-to-maximum values, while the manuscript caption describes standard deviation; that helper has not been established as the source of the final figure. It is therefore not used to relabel or change the original image. Confirming the original plot provenance remains an author record requirement. The linkage-depth figure's complete per-repeat table was not recovered from these files; an unrelated iteration-versus-error CSV is not relabelled as linkage-depth source data.
